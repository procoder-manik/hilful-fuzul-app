এই ফোল্ডারে শুধু নতুন বা বদলানো ফাইল আছে (আগের সব ধাপসহ)। একই জায়গায় কপি করে Replace করুন। এবার package.json ও .env.example ও বদলেছে (শুধু নতুন লাইন যোগ হয়েছে), তাই ওগুলোও Replace করুন, কিন্তু আপনার নিজের .env.local ফাইল বদলাবেন না।

জরুরি ধাপ (ক্রমানুসারে):
1) Supabase > SQL Editor এ supabase/migrations/009_security_email.sql চালান।
2) টার্মিনালে npm run gen-key চালিয়ে যে কী পাবেন, .env.local এ DATA_ENCRYPTION_KEY= এর পরে বসান (এবং কীটি আলাদা নিরাপদ জায়গায়ও রেখে দিন)।
3) Resend এর RESEND_API_KEY ও RESEND_FROM .env.local এ বসান। Vercel এ থাকলে Vercel এর Environment Variables এও একই মান বসিয়ে Redeploy করুন।
4) Ctrl + C দিয়ে সার্ভার বন্ধ করে আবার npm run dev।
5) অ্যাডমিন > সেটিংস > নিরাপত্তা থেকে 'আগের জমা তথ্য এখনই এনক্রিপ্ট করুন' বোতাম একবার চাপুন।
